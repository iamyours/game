# 放行标准

## 二十 物理手感验收

### 必看一段连续过程
G1 建议录制 60 至 90 秒：先展示两次普通中距离射击，再依次命中头、腰、持弓臂和膝；展示掉弓、掉盔、坠台；最后展示玩家倒地后瞄准发射。附上速度、距离、关节权重和冲量配置。

| 项目 | 放行标准 |
| --- | --- |
| 飞行 | 中距离有可观察过程 箭头方向与速度一致 |
| 命中 | 四类部位反应能在无粒子模式下区分 |
| 插箭 | 跟随命中部位 不漂浮 不持续抖动施力 |
| 失衡 | 受力带动重心变化 不是固定播放倒地动作 |
| 装备 | 弓盔脱落有连续位置与速度 只生成一次 |
| 坠落 | 从平台边缘到离开视野的过程可见 |
| 控制 | 倒地仍可瞄准 取消输入后停止新发射 |
| 稳定 | 连续运行无爆炸 无身体明显分离 |

### 产品评估办法
产品负责人在同一设备试玩，分别评价飞行期待、命中反馈、倒地控制和画面可读性。采用 1 至 5 分并留下具体原因，首轮目标每项至少 4 分；分数用于对比方向，不宣称是客观性能指标。

先看不带粒子版本，再看完整表现版本。若完整版本更热闹但无法辨认手臂和膝部，不能因此提高命中反馈评分。调参一次只改变少量相关变量，保留前后配置，避免无法知道改善来自哪里。

### 不通过的典型情况
箭一发出便命中；所有部位只触发同样的整身平移；身体被强回正立即拉直；敌人直接消失而没有倒地坠落；特写时玩家被屏外箭击杀；敌人掉弓仍射箭；玩家倒地后箭从固定出生点发出。

这些问题优先回到对应任务修复，不通过新增数值成长掩盖。全部物理必测用例通过且试玩方向得到确认，才将 T008 标为 DONE。
