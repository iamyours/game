## 已接入代码

- 敌人从自己的实际右前臂握点发出真实 ProjectileSystem 箭。使用 EnemyAttack 的首次延迟/蓄势、冻结预测瞄准和误差；红弦表示蓄势。没有用延迟扣玩家血冒充射箭。
- 轻/重弓手随机选择生命、攻击间隔和伤害；目前都没有头盔。平台x约16.8–20.5m、台面y约3–6.3m、宽1.6–2.8m。候选经过普通箭静态抛物线可达检查，不等于实际地形/身体阻挡验收。
- 血条跟随头部世界位置，受伤身体片染红，并在其关联铰链锚点画红点。红标保留到角色回收/重开。
- 连续模式中无甲敌人的有效爆头伤害直接结算剩余生命。死亡后在 after-step 禁用/销毁颈铰链，头仍是独立动态刚体，保留命中冲量与重力。身体命中保持既有分部位伤害。玩家仍用普通HP结算。
- 敌人死亡或跌出失败线后，平台从静态切成动态刚体；身体停止主动驱动，弓从真实握点分离并继承持弓前臂速度。1.2秒后生成新敌人/平台；旧尸体、头、平台和弓3.5秒后回收。
- 动态目标注册/注销、插箭清理、factory实例移除防止旧敌人一直占用逻辑列表。死亡只计分一次。玩家死亡/坠台后停止新敌人攻击与生成，画面显示击败数，点重置重新开始。暂停依靠唯一固定步冻结所有计时。

以上集成代码尚未在本环境构建运行。随机角色目前复用两种生命/攻击配置与同一敌人皮肤，不包含原作全部精灵、特殊箭、成长菜单、多敌并行、果实或随机机关。旧三关配置仍保留，默认循环不走解锁链。
