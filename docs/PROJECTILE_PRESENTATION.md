# D033 箭矢残留、重量表现与横屏全屏（2026-11-13）

基线main `6795b5d`；按用户本轮反馈继续实现。当前是代码与离线绘制检查完成，Creator构建、物理/全屏实跑及手机验收仍待执行。

## 改了什么

- 插箭原来只有数量上限、没有存留时限。现在身体每人最多3支、单平台最多2支、全场最多16支；分别保留4秒/2.2秒，最后0.6秒平滑淡出。时间使用唯一固定步，暂停不计时。目标回收、父节点失效、离屏及重开均清理；回收立即停止显示再等帧末销毁，单个租期只释放一次。
- 普通/冲击/穿甲箭长度从0.96/1.02/1.10m改为1.28/1.38/1.46m；同步搭箭、实际发射尖、飞行、插箭与敌箭。扩大箭头/尾羽和明暗描边，雷霆贴图保留程序轮廓衬底，避免缩小后只剩细线。弓半高0.64→0.74m，机械纹理横向映射0.45→0.8，握点与连续剪切保持固定，不改身体碰撞。
- 箭朝向跟随原生速度；新增最多6个固定步采样、最长0.85m的短箭迹，只画已经飞过的路径。回收清理速度和箭迹，复用时显式恢复gravityScale=1、零阻尼。保持真实-9.8m/s²重力、原箭速/伤害/击退，不靠延迟扣血、额外施力或降速悬浮制造重量感。飞行箭5秒寿命继续保留，超出当前视野安全余量也回收。
- 连续模式固定视野以(11.6,4.55)m为中心，核心宽21.8m；实际高度为max(11.7,21.8/aspect)m，超宽手机不继续扩高而缩小人物。保留玩家平台左缘、最远敌人与最高出生点，下方至少保留约4.3m可见坠落。当前布局通过纯几何检查，不是自然坠落运行验收。练习模式保留原24×13.5m标定视野。
- 连续模式去掉大块触摸底板和底部调试长句，改为左上击败/最高分、生命/体力细条、右上紧凑操作、右下切箭。隐藏热区保持原规则。按钮按至少48 CSS逻辑像素和真实安全区布局，超宽屏使用两侧空间。背景覆盖全视野，加入低对比远景和平台亮边；不遮挡箭与关节。
- Web壳固定铺满窗口、支持动态视口高度与安全区。支持标准Fullscreen API时显示“全屏/退出全屏”，只在用户点击后请求；不支持的宿主不显示该按钮。全屏切换清旧触摸，不恢复待发箭。未承诺iOS/微信网页可以隐藏系统栏，小游戏宿主仍单独验收。
