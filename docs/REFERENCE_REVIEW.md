## 本轮修改

1. 保留真实双手就位、弓口阻挡和在途箭预算检查。增加 `lastAttempt`：物理步编号以及 hands-unready / muzzle-blocked / arrow-limit / fired，进入 snapshot 与拒射提示。弓口红色表示受阻，橙色表示双手未到位。
2. 输入记录 too-short / cooldown / queued，取消清反馈；新增测试证明拒射不会在稍后补发。
3. 方向提示收回至 0.15 秒、五个点，仍用同一力度速度与固定步重力，无输入时不显示提示。
4. npm 脚本改用 `node --import tsx`，避开 tsx CLI 的 IPC socket 在受限环境中的 EPERM；不更换引擎或依赖版本。

倒地未放箭的根因仍未确定。历史失败报告 `evidence/T004/release-to-fire/probe/web-verification.json` 记录 downed release shoot 超时；最终快照 hands.ready=true 不等于释放当步 ready，且旧版没有拒射原因。不能因此宣称 IK 或弓口阻挡就是已证实根因。
