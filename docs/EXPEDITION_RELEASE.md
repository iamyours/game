# D039 / D040 命中重量、音乐与远征目标

本轮是可供Creator导入的功能迭代，不是发布验收通过。基线main d1bbbb2；锁定Creator3.8.8和原Box2D/单固定步。

## 命中和人物

插箭保持纯视觉附着：真实命中后45ms内深入，箭尾在身体320ms/平台220ms内衰减摆动；身体材质盖住箭尖。寿命、全场/目标容量、去重和回收沿用原策略，暂停时不前进。没有新增插箭刚体。

局部/躯干共享原一次冲量预算，三箭12/22/8.5N·s及玩家2.4N·s保护不变。传递到胸部的作用点保留命中位置，胸部中心相对力臂限制为横向±0.22m、纵向±0.30m，避免腿部远端杠杆失控。关节控制先保持受创权重最多120ms，再平滑恢复；不强制后仰、不改刚体变换。真实稳定和手感仍待验证。

头颈空隙来自透明领口与圆形下颌的素材拼接。短颈底层按实际胸/头坐标连接，随侧仰和倒地更新，位于衣领/头部图层下方；不挪动碰撞头部，也不断颈。

四首音乐由scripts/generate-music.py原创合成，不使用第三方录音；16小节、立体声、Vorbis OGG。三场景曲40–51秒，BOSS曲约34秒；旋律、和弦、低鼓与延迟尾音可复现。音乐体积合计约1.1MB；解码检查不等于真实听感。双AudioSource约600ms交叉渐变，首次用户交互后播放；暂停/后台/竖屏/强化选择/死亡静音暂停，继续后恢复。独立音乐/音效开关，偏好跨启动保存。实际Web/Android/微信解码和循环听感待验。

## 继续玩的目标

挑战循环：爆头击败3名→符石；不受伤连续击败3名→药瓶；再击败5名→当前弓升级。只由after-step唯一击败结算推进；受伤中断连杀及当前无伤目标，死亡同帧不发消耗品。药瓶已满改回复15生命，符石已满改蓄能25，满级弓改技能蓄满，提示展示实际替代结果。

修炼独立于本局强化：每击败1经验、爆头额外1、BOSS额外4；阈值0/8/25/55/100，五级称号。下一局伤害每级增加2.5%，封顶10%，不在战斗中途生效；不加射速/冲量、不锁原有弓箭。结算显示最高连杀、修炼和下局加成。本局道具、技能、段落强化、挑战、连杀和场景仍在重开时重置。

career使用独立storm-archers.career键，不修改历史关卡或最高分存档。累计检查点重复提交不重发经验，写入失败保留内存并在重复检查点/后台/退出/重开重试；坏档先备份，未知未来版本及读取失败不覆写。仅本地存档，无账号/云同步。音乐偏好随career保存；UI同时报告任一记录写入失败。
