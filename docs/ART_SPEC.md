# 美术资源规范

## 十 场景和精灵制作规范

### 视觉方向
沿用风暴浮空遗迹的青蓝环境与琥珀弓箭配色。天空、远景、平台、角色和特效分层，敌我轮廓在缩小后仍能区分。平台下方保持低干扰，便于观察身体与装备坠落。

角色采用轻装、圆头、分段肢体，减少覆盖肩肘膝的厚重护甲。胸骨盆分开，关节处留清楚的轮廓连接。冲击箭以箭头形状和短拖尾区分，不用整片光幕遮住身体。

| 资源组 | 首版交付 | 关键要求 |
| --- | --- | --- |
| 英雄 | 11 个身体片 弓 箭 轻围巾 | 锚点和物理尺寸对齐 |
| 普通敌人 | 身体片 弓 两套配色 | 轮廓清晰 可重复组合 |
| 装甲敌人 | 通用身体 独立头盔 护甲片 | 可脱落装备单独出图 |
| 首领 | 通用结构的放大变体 | 单独调质量与驱动力 |
| 场景 | 天空 远景 云层 三种平台端块 | 平台台面与碰撞边缘一致 |
| 特效音效 | 离弦 肉身 金属 断裂 坠落 | 先区分材质 再加装饰 |

### 切片与挂点
图片交付透明 PNG 与源文件，每片记录原尺寸、关节挂点、朝向与命名。关节挂点使用资源像素坐标并明确原点，导入时统一转换。骨架碰撞尺寸来自 RigDefinition，不由自动裁切后的图片包围框直接推导。

弓弦采用程序线段或简短动画，不模拟真实弹性绳。围巾和装饰先用轻量视觉动画，不额外堆叠刚体。大型首领不能只把物理父节点整体缩放，应由工厂根据体型重新生成尺寸、质量和关节。

### 接入顺序
灰盒姿态通过后，先替换英雄和敌人身体片，复查命中位置；再接平台和背景；最后加音效、拖尾和命中粒子。每步保存相同场景的前后录屏，发现受击不可读时先降低背景和特效强度。
