# T004 受限关节与倒地驱动

本轮基线 3760c6d；继续收敛当前物理射击，不提前扩关。Creator 3.8.8 当前不可用；以下为已实现且规则测试通过的候选修复，不是已验证的手感结果。

## 为什么肩关节会顶住

肩关节范围为 -160°～160°。旧控制器对 `target-current` 做 normalizeDegrees：当当前150°、目标-150°时，-300°被折成+60°，随后向正方向驱动，最终顶住+160°。这条整圈短路要穿过禁止区间。两段IK即使给出可达目标，关节也可能一直到不了。

新控制器先把目标夹到合法区间，再直接用目标减当前角，不归一化角差。上述例子输出负向速度；反向例子输出正向速度。保留增益7、原速度上限和全部关节限位，不直接写刚体角度。每个关节按配置做方向测试；额外的数值积分用例仅验证控制律，不作为引擎运行证据。

## 倒地不要继续拗身体

旧 Downed 虽停了胸部竖直平衡力矩，但腰、髋、膝仍用12 N·m量级的有限马达追固定折叠角。倒地演示仍可能被预设姿态牵动。

现在显式设置 Downed 时，立即清掉躯干/腿部遗留驱动并退出出生高扭矩预热。后续步中颈、腰、髋、膝最大主动扭矩和马达速度为零，仍保留被动铰链限位。双臂继续世界IK，基础权重0.8，仍叠加本轮之前的受击/臂伤恢复；活体倒地与死亡分开。死亡控制仍全为零，reset走原工厂恢复。

本轮没有新增按胸角自动判断倒地、自动起身或捡弓；正式战斗如何把实际失衡接入姿态状态，仍须结合真实物理验证。弓口受阻/双手未到位仍拒射，不移动弓口穿身，不排队补射。三箭速度、冲量和受击恢复参数未改。
