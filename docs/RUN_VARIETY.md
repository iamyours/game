# D038 连续对战的变化、装备与BOSS

基线：main `59fac0d`。用户要求解决久玩重复，并明确追加定期BOSS、道具、装备切换升级和技能特效。本轮直接接入默认连续模式；练习入口保留。以下数值为待Creator试玩标定的候选值。

## 一局的节奏

每击败5名敌人清一段。第5、10战为精英，第15战替换为BOSS“遗迹守望者”；之后每15战再次出现。开局前两名为普通弓手，其后快弓猎手、神射手与重弓守卫交替随机，相邻特殊敌人不重复。平台仍经过原生占用查询与原可达性检查，猎手使用原有运动学摇台。

| 遭遇 | 实际差别 |
| --- | --- |
| 快弓猎手 | 1.9–2.3秒间隔、0.42秒蓄势、较大瞄准误差、摇台 |
| 神射手 | 3.1–3.5秒间隔、0.95秒蓄势、0.8度瞄准误差 |
| 重弓守卫 | 沿用85HP与1.35倍真实质量，无头盔 |
| 精英 | 100HP，半血后的攻击间隔乘0.85，头部仍可致命 |
| BOSS | 180HP；第一阶段发冲击重矢；半血后发普通箭、攻击间隔乘0.65；头部按原2倍伤害，不触发普通敌人即死覆盖 |

BOSS复用当前同尺寸骨架，使用金色调、冠形标识与独立大血条；未添加未经标定的巨型骨架。玩家依旧可以通过击伤持弓臂、失衡和坠台制胜。BOSS失弓阈值为普通敌人3倍，失弓后不会继续发箭；没有血腥或断肢。

段间停止新发射和刷新，等所有在途箭真实结束；同一步玩家死亡优先，不允许用奖励复活。只有安全后才打开强化模态并暂停唯一物理时钟；选择一次后恢复，不补发旧触摸。无效选择、拖出按钮、取消、后台与旋屏都不确认。

## 装备、技能和道具

右侧增加切弓、技能、药瓶和符石按钮，原切箭按钮保留。装备与弹药独立；切弓不抢左手瞄准、不重置共享冷却或技能蓄能。

| 弓 | 常态 | 主动技能 |
| --- | --- | --- |
| 雷霆弓 | 均衡，保留机械纹理皮肤 | 雷霆一击：下一箭伤害2倍，青蓝电光短迹与命中电纹 |
| 疾风弓 | 伤害0.85倍、间隔0.8倍，绿色折线弓形 | 疾风三连：下三箭伤害1.2倍、间隔0.5倍、耗体力0.5倍，绿色风纹 |
| 月蚀弓 | 伤害1.3倍、间隔1.2倍，紫色反曲轮廓 | 月蚀重矢：下一箭伤害3倍，紫色短迹与双环月纹 |

技能开局满蓄能；每模拟秒恢复5，真实玩家命中+10、击败+15，最高100。点击技能只准备效果，仍需一次次松手射箭。技能效果锁定激活时的弓，切弓不偷换成另一技能；已准备效果尚未用完时不能叠开。所有装备与强化的最短发射间隔为0.2秒。

技能和符石均只在ProjectileSystem成功生成真实箭后消耗。预览、取消、受阻、未就位、体力或冷却拒射不消耗。所有技能保持真实箭速、重力和原单次冲量预算，不产生额外自动箭。命中伤害来自同一支真实箭的配置。

- 药瓶：开局2瓶，点击回复最多35HP。满血、死亡或无库存不消耗。
- 符石：开局1枚，点击使下一支成功发射的箭伤害增加50%，可与技能叠加；已准备时不重复消耗。
- 库存每种最多3。连续模式射中红色补给收药瓶，金色收符石，绿色仍立即恢复体力。库存满时药瓶折为15HP、符石折为25技能蓄能；敌箭不能收取，单次收取去重。练习/旧规则构造器默认保留原红绿补给行为。

## 强化和战利品

每5次击败从可用项中无重复抽最多3项：快弦（每级间隔-10%）、普通箭伤害（+25%）、冲击箭伤害（+40%）、穿甲箭伤害（+35%）、耗体力（-20%）、休整或锻造。普通强化最多3级，满级移出池；全部满级且当前弓无法锻造时只提供休整，不提供无效卡片。

锻造升级当前弓，每级伤害相对基础+15%，最高Lv.4；三把弓的等级独立，切换后保留。本局重开清空全部等级和强化。普通强化附赠10HP并补满体力，休整回复35HP并补满体力。

BOSS只结算一次战利品：当前弓升级一级（受Lv.4上限）、符石+1（受库存3上限）、技能补满；随后仍有一次强化选择并回复35HP、补满体力。奖励不能复活。敌人基础攻击间隔每段最多缩短6%，到第5段累计24%后封顶，HP不无限增加。

数值入口：`domain/RunProgression.ts`的RUN_RULES、PERKS与遭遇配置，以及`domain/BattleLoadout.ts`的BOWS与射击修饰。原combat.seed中的物理、三箭初速/冲量与生成配置哈希保持；旧heavyChance/rockingChance的随机分配在D038由遭遇规则覆盖。

## 所有权和验证

ArcadeBattle拥有RunProgression、BattleLoadout、真实遭遇和战利品；PhysicsLab拥有输入模态与原ShotBudget。HitResolver通过按目标查询排除BOSS的头部即死，但保留正常部位伤害。ProjectileArrowConfig可携带skill标记，沿原飞行/扫掠/去重/命中流程传递。

特效仅使用现有Graphics：固定步计时、最多16个短事件（0.32/0.42秒），飞行短迹仍受原0.85m预算，暂停冻结，过期或重开清空；不加物理体、墙钟定时器或第二套步进。

便携测试覆盖段界、共享冷却、Boss出现/半血攻速、真实HitResolver中的头部规则、死亡与奖励去重、锻造/库存上限、实际技能扣次、100段数值上限及48像素按钮。UI夹具运行生产HUD/处理器，检查切弓不抢手、技能不自动射、用药、取消、强化模态与手机布局。预览人物为摆姿，绝非Creator试玩。
