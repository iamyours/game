# PhysicsLab 开局掉落回归

场景 Boot → PhysicsLab；Cocos Creator 3.8.8 / Box2D JS，桌面 Chrome WebGL。

- 旧构建：普通冷启动的 30 秒静置和额外固定步未重现坠落（`repro/`、`long-before/`）；加上 Boot 重载夹具探针后，确认三个平台创建瞬间的原生掩码均为 `1`，缺角色和箭组（`filter-before-final/`，退出 1）。后续引擎同步可能重建夹具而掩盖缺失。
- 仅修夹具顺序后，原生掩码为 `7`，但重新载入后站台断言仍失败（`filter-only/`，退出 1）；单独叠加胸部限幅力矩也未通过（`torque-only/`，退出 1）。短 trace 显示靶手腿部逐渐滑移后侧倒，未受击胸高约 3.28 m（`balance-trace/web-verification.json`）。
- 保留可退出的胸部力矩，站姿改为两侧髋关节小幅对称外展、膝目标回到零，扩大支撑面而非锁住人物。`stance-probe/` 是参数探索（非交付验收）；最终运行结果以 `after/` 为准。
- 最终构建（`after/web-verification.json`，退出 0）：平台原生掩码全部为 7；30 秒墙钟共采样 265 次、观察 1794 固定步，双方最低胸高 4.527 m、最大横向漂移 0.079 m；同一 Box2D 世界额外运行 3600 固定步仍站台，最低胸高 4.528 m、最大累计漂移 0.208 m。20 次重置后两人重新站稳，27 刚体/20 关节（原生含内部地面 28/20），无页面或控制台错误。
