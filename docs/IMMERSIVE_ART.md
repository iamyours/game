# D036 GPT 生图：风暴遗迹素材接入

2026-11-13。用户要求背景、人物、站台使用 GPT 生图提升沉浸感。本轮使用内置 GPT 生图生成四张素材，原始 PNG 原样复制到工程，旧素材保留。完整逐张提示词见 [IMMERSIVE_ART_PROMPTS.json](IMMERSIVE_ART_PROMPTS.json)。没有通过程序画图替代生图，也没有对生成图做程序重绘、改色或去背。

## 接入方式

- 连续模式 CharacterSkin 优先加载 v2 图集，练习模式沿用原角色；新资源未导入或失败时回退经典图集，经典图集失败才保留灰盒。元数据由实际 alpha 主连通区域测量，仅指定 SpriteFrame 裁切，不编辑图像。人物原始图集的额外边缘碎片不进入有效帧。
- 原11刚体的尺寸、关节、锚点和握点保持；新图仍在原视觉子节点上。敌人图像子节点水平翻转，让侧脸朝向玩家，物理节点不负缩放。
- RuinsArtAssets 场景级共享两张环境纹理和4个SpriteFrame；平台分左端/中段/右端，端块固定0.38m，中段适应随机宽度，整体仍为原 width×0.6m。精灵继承已有平台旋转/坠落，不添加碰撞或刚体。
- 背景按当前相机 cover 等比铺满，尺寸改变时重新适配；保持同一全景镜头，无逐箭追踪。背景中的建筑仅为远景画面，不增加可站立地形。
- 新平台图片就绪前保留程序绘制，全部切片创建后才关闭回退 Graphics；场景退出或平台回收后的迟到资源不会创建精灵。资源失败只警告一次，继续使用回退场景。
- HUD加小范围深色衬底，避免亮天空/山脉穿过文字，战场本身不加整屏暗层。

新图、新JSON、新目录和RuinsArtAssets.ts的meta均须由真实Creator3.8.8导入生成，不手写UUID。清单与SHA-256在 assets/resources/scenery/ruins-art-v2.json。原PNG保留，资源回退路径保持。
